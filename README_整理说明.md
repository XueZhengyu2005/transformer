# transformer 源码与文档整理版

本目录是从上层 `transformers_tasks` 项目中**独立复制的源码与文档**。按照整理要求，**不包含训练后的模型、预训练模型、数据集、评估 JSON/JSONL、运行日志、生成图片或缓存**；没有使用符号链接或硬链接。上层原项目及其模型、结果文件未受影响。

## 包含范围

- 项目 Python、Shell 与 Notebook 代码；Notebook 中只保留代码和说明，已清除单元格运行输出。
- 根目录和各任务的 README、依赖声明、[实验报告.md](./实验报告.md)。
- 极少量属于**代码配置**的文本：PET 的提示模板/verbalizer、P-Tuning verbalizer、文本匹配类别说明。它们不是训练语料。

## 使用说明

本目录用于阅读、修改代码和提交报告，**并非开箱即可推理或重新训练的模型包**。需要运行脚本时，请另行提供各任务的数据集与 `model_best` / PPO `final` 权重、tokenizer 和配置。ChatGLM-6B 是单独的预训练依赖；运行其三个应用示例时，应另行准备模型，并通过 `MODEL_ROOT` 环境变量指定模型的父目录。该目录不包含 Python 环境：历史实验使用 Python 3.12.3、PyTorch 2.8.0，base 和 trans 两套 Transformers 环境的说明见 [实验报告.md](./实验报告.md)。

根目录 [readme.md](./readme.md) 和各子项目 README 沿用原项目的训练与推理说明，其中的模型、数据、曲线图路径表示**需要自行提供的运行资源**，不是整理版中的现有文件。`reproduce.sh`、`tools/verify_t5.py` 等代码也需要这些资源才能运行。

[实验报告.md](./实验报告.md) 记录了原项目 2026 年 9 月 29 日已完成实验的方法和结果；报告中出现的模型、预测结果及日志路径指向**上层原项目的实验记录**，整理版没有附带这些产物。
